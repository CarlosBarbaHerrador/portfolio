Chronicles of Aethoria (RPG de Texto con IA)

Videojuego de rol de texto para un solo jugador donde un Dungeon Master virtual impulsado por inteligencia artificial interpreta el mundo y narra la aventura en tiempo real.

Arquitectura y Funcionamiento

  • Motor de IA Integrado: Conexión avanzada con la API de Groq empleando modelos de lenguaje optimizados (Llama) para actuar como narrador dinámico y motor de reglas de rol.
  • Aplicación de Escritorio Nativa: Construido con el framework Tauri, combinando un rendimiento nativo ultraligero con una interfaz de usuario moderna en React y TypeScript.
  • Gestión de Estado: Control robusto de estados de juego, inventarios, combates y narrativa persistente por parte del jugador.

Stack Tecnológico

Tauri React TypeScript Groq AI API
