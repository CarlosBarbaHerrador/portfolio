Automatización & Bot Telegram

Bot de Telegram (Recordatorios & Periodos)

Bot backend en Python ejecutándose 24/7 en servidor local para la generación y envío automatizado de resúmenes periódicos de datos y gestión interactiva mediante comandos.

Arquitectura y Funcionalidades

  • Integración con Google Sheets y Archivos: Lectura y procesamiento de hojas de cálculo y registros locales con librerías especializadas (Pandas, OpenPyXL).
  • Bucle de Escucha Activa (Long Polling): Servicio residente en Ubuntu Server contenedorizado con Docker para operación continua.
  • Comandos Interactivos: Gestión de consultas en tiempo real mediante comandos personalizados (/periodo, /agregar, /verganancia).

Stack Tecnológico

Python PyTelegramBotAPI Pandas & OpenPyXL Docker / Ubuntu
