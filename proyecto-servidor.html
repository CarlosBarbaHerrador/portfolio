Infraestructura & Servidor Casero (24/7)

Plataforma de servidores autohospedada sobre hardware dedicado Lenovo ThinkCentre M710q, configurada para orquestar microservicios, bots de mensajería y aplicaciones web con alta disponibilidad.

Arquitectura y Hardware

  • Hardware Base: Lenovo ThinkCentre M710q equipada con procesador Intel Core i5-7400, 8 GB de memoria RAM DDR4 y almacenamiento SSD NVMe de 256 GB.
  • Sistema Operativo: Ubuntu Server configurado para gestión desatendida y despliegues optimizados en la ruta raíz ~/proyectos/.
  • Orquestación de Contenedores: Gestión centralizada mediante Docker y Docker Compose con políticas de reinicio automático (restart: unless-stopped).
  • Redes y Seguridad Pública: Implementación de Caddy como proxy inverso de alto rendimiento y DuckDNS para resolución de DNS dinámico, gestionando certificados SSL/TLS automáticos (Let's Encrypt).
