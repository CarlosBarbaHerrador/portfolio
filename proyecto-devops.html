DevOps & Seguridad

DevOps & Ciberseguridad Labs

Laboratorio integral enfocado en la automatización de despliegues, monitorización de infraestructura en tiempo real y desarrollo de utilidades defensivas de seguridad.

Componentes del Laboratorio

  • Observabilidad y Métricas: Configuración de Prometheus para recolección de métricas de sistemas y Grafana para visualización de dashboards de rendimiento.
  • Aprovisionamiento Automatizado: Uso de Ansible para la configuración estandarizada de servidores y despliegue de contenedores.
  • File Integrity Monitor (FIM): Herramienta defensiva desarrollada en Python para la detección de modificaciones no autorizadas mediante funciones hash SHA-256.
  • SecureVault: Gestor de contraseñas CLI basado en cifrado simétrico avanzado (AES / Fernet y derivación PBKDF2).
