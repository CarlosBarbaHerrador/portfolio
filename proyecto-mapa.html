GIS & Python Automatización

Mapa Interactivo & Vectorización GIS

Sistema cartográfico web interactivo conectado a base de datos en la nube y automatizado mediante scripts de procesamiento de imagen en Python para vectorización poligonal.

Características Técnicas

  • Procesamiento OpenCV (vectorizar.py): Extracción automatizada de polígonos vectoriales desde mapas ráster de alta resolución con auto-escalado proporcional.
  • Sincronización con Supabase: Inserción y actualización en tiempo real de geometrías, metadatos y categorías de elementos geográficos.
  • Infraestructura Servida: Desplegado en entorno local Ubuntu Server y publicado de forma pública y segura mediante proxy Caddy con DuckDNS (https://mapa-interactivo.duckdns.org).
