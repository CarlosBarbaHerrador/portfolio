Automatización & Bot Discord

Bot de Encuestas Programadas (Bot-Encuestas)

Sistema automatizado en Python para la creación, envío y recuento periódico de encuestas de disponibilidad semanal dentro de servidores de Discord.

Arquitectura y Funcionalidades

  • Tareas Asíncronas y Cron: Programación temporal robusta para la publicación automatizada de cuestionarios sin intervención manual.
  • Health-Check HTTP: Servidor integrado en el puerto 8080 para monitorización de estado y validación de disponibilidad en la plataforma cloud.
  • Despliegue Cloud: Integración continua y alojamiento en Render para asegurar estabilidad constante.

Stack Tecnológico

Python Discord.py Asyncio / HTTP Server Render Cloud
